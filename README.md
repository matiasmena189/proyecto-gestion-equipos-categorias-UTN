# proyecto-gestion-equipos-categorias-UTN
Proyecto universitario, ejercicio de parcial de la materia Algoritmos y Estructuras de Datos. 
Gestión de Equipos y Jugadores por Categorías
Descripción
Proyecto de la Universidad Tecnológica Nacional realizado a modo de practica para los parciales de la materia Algoritmos y Estructuras de Datos 
Utilizo estructuras dinámicas para representar los clubes y sus respectivas listas de jugadores.
*Cabe aclarar que las funciones de insertar, buscar, liberarMemoria no están desarrolladas ya que no era lo pedido*. 

Conceptos y herramientas utilizados:
Lenguaje C++.
Estructuras (struct).
Punteros.
Listas enlazadas.
Listas anidadas y sublistas.
Manejo de archivos binarios.
Lectura de registros mediante fread().
Búsqueda y recorrido de estructuras dinámicas.

Este ejercicio se basa en la creacion de una lista de Equipos donde habrá jugadores para cada equipo en base a sus categorias.
